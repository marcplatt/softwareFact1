Where does the work happen?

ArtifactPurpose
app/db/schema.tsApplication-side table descriptions, TypeScript information, and ORM defaults.
drizzle.config.tsTells Kit which schema, migration directory, and database to use.
drizzle/*.sqlVersioned instructions for changing the actual database.
drizzle/meta/Snapshots and metadata used for migration generation.
data.dbSQLite’s persisted structure and rows.
app/db/index.tsOpens the connection and creates the ORM wrapper.

Vocabulary

ORM: object-relational mapper; here, Drizzle bridges application objects/types and SQL operations. Driver: the library through which the application executes database statements. Schema drift: disagreement between the application’s declared structure and the database’s actual structure.

Remember

Editing a declaration changes application assumptions. Applying a migration changes the database. Executing a query uses the structure already installed in the database.
