Lesson 01

Read, locate, compare

For each rule: what does it guarantee, where is it enforced, and which requirement justifies it?

Vocabulary

TermMeaning
Primary keyIdentifies a row.
Foreign keyRequires a reference to an existing parent, subject to enforcement and nullability.
Composite unique indexPrevents duplicate combinations and provides an indexed access path.
Runtime defaultA value supplied by the ORM; independent SQL writers do not receive it.
MigrationSQL that changes the actual database structure.

Five reading questions

  1. What does one row represent?
  2. Which values are required? Is empty text acceptable?
  3. Which combinations must be unique?
  4. What happens when a referenced parent is deleted?
  5. Which rules live only in application code?

Index order

The existing (user_id, lesson_id) index supports pair lookups and user-leading queries. Lesson-only queries may need a separate index; decide from actual queries and query plans. SQLite query planning.
