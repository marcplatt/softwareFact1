What would make this fail?

For each test, name its contract, boundary, distinguishing setup, and decisive assertion. Then imagine a concrete broken implementation.

TermReview question
BehaviorWhat result matters to the caller?
SeamWhich public boundary does this test exercise?
RegressionWhich previously working behavior could break?
RefactorCould internal code change while these expectations stay valid?
Red → greenWas the test observed failing for the intended missing behavior before implementation?

Database inserts can arrange a scenario without dictating the implementation of the behavior being asserted. Multiple assertions can establish one coherent scenario.

A passing test provides evidence within its exercised boundary. It does not establish how it was developed or validate a boundary it bypasses.

Sources: Beck, Canon TDD; Google, Test Behavior.
